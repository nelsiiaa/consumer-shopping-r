Methodology

Tools & techniques

Each question was explored with purpose-built visualisations using a consistent design system.

Data manipulation

  • Grouped summaries with group_by() + summarise()
  • Tidy reshaping via pivot_longer() / pivot_wider()
  • Stratified sampling with slice_sample()
  • Quadrant segmentation using case_when()
  • Correlation analysis with cor()
  • Weighted means via weighted.mean()

Visualisation techniques

  • Multi-aesthetic bubble charts (size + fill + facets)
  • Violin + jitter plots with mean diamond overlay
  • Diverging bar charts with coord_flip()
  • Lollipop charts with scale_color_gradient2
  • 100% stacked bar chart with percent labels
  • Confidence ribbon + linear trend line overlay
